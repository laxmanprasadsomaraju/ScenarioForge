# Final demo script (draft, Lane 3, 2026-11-11)

Eight stages. Each stage says what is **live** (read from the real Jira/Confluence demo site), what is **simulated** (modelled on a simulated clock) and what is an **operational change** (none are made). Only capabilities Live verified in [CURRENT_STATUS.md](../CURRENT_STATUS.md) are shown as working; the rest are conditional or omitted. Timing and shot list: [STORYBOARD.md](STORYBOARD.md). Setup: [DEMO_SETUP.md](DEMO_SETUP.md).

Narration rules: say "modelled" or "simulated" for every rehearsal minute. Data is synthetic and labelled `[DEMO]`. Never say "prevents incidents", "guarantees" or "certifies".
