# Security and privacy checklist

For the judged build (recommended: `confluence-test` scope set) and, where noted, `rovo-test`. Sources: [PERMISSIONS_AUDIT.md](PERMISSIONS_AUDIT.md), [../SECURITY_BOUNDARIES.md](../SECURITY_BOUNDARIES.md), [../AI_USAGE_GOVERNANCE.md](../AI_USAGE_GOVERNANCE.md), [../marketplace/PRIVACY_POLICY.md](../marketplace/PRIVACY_POLICY.md).

| ✓   | Item                  | Judged build                                                                                                                                                                  | `rovo-test` difference                                                                                                                                      |
| --- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ☑   | Data stored           | None. No `storage:app`; rehearsals and reports live in the browser tab only                                                                                                   | `ai-governance` (usage ledger, settings, response cache) and `rehearsal-history` entities in Forge storage, keyed by account id                             |
| ◐   | Retention             | Nothing retained server-side; closing the tab discards rehearsal state                                                                                                        | Response cache TTL 900 s, 200 entries; history retention policy to be stated before any non-test deploy                                                     |
| ☑   | Egress                | None: no `permissions.external` in any manifest. Runs on Atlassian (Forge hosting only)                                                                                       | Same                                                                                                                                                        |
| ☑   | Writes                | None. No write scope; remediation is a preview                                                                                                                                | Same (all four actions are `GET`)                                                                                                                           |
| ☑   | Identity              | Every product call is `api.asUser()`; results limited to what the user can see. No `asApp` product calls                                                                      | Actions verify the context account id and call `asUser()` (`src/agents/actions.ts`)                                                                         |
| ☑   | AI usage              | None. Findings and verdicts come from the deterministic engine                                                                                                                | Rovo explains and cites only; grounding check; budget cap 300/user/day; AI off until `SF_ROVO_TEST_AI=enabled`                                              |

| ☑   | Input validation      | Space key validated (letters and digits); CQL injection rejected (`test/confluence.test.ts`)                                                                                  | Action inputs validated (`test/agentActions.test.ts`)                                                                                                       |
