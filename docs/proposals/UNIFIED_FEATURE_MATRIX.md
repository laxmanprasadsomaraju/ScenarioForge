## Gaps against the old UI (`origin/rovo-test/session-id`)

Method: file-level diff of `static/app/src`, string-by-string search of the old UI's user-visible text in the new source, and a per-file count of component tests. Every old component test file exists here with the same or more tests (old 76 -> new 83 in those files; one old test was renamed "offers a first check from the Command center"). The old `Evidence.tsx`, `TimeRail.tsx`, `Objectives.tsx` and `SaveNote.tsx` are present. Nothing from the old UI is missing as a function. Differences, all deliberate:

- **Routes**: same eight paths, same ids. `pages/Planned.tsx` (the "Planned for M7" Crisis room page) is removed because the Crisis room is real.
- **Nav labels**: Overview -> "Command center"; Recovery plans -> "Runbooks"; Simulations -> "Rehearsals". Paths unchanged.
- **Overview**: the old "Recovery readiness" and "Recovery risk" tiles ("Rule-based, demo"), the "Planned for M8" tag and "Start the demo rehearsal" are replaced by a journey strip, "Next action", a "Figures" row of counts that start at 0 or "Not assessed", and "Try the synthetic demo". No invented figures.
- **Readiness**: source quote labels "What the change says" / "What the runbook says" -> "Jira change, quoted" / "Confluence step, quoted". New "What was not checked", "Show query", impact-path "Sources" table.
- **Rehearsal**: the single "Evidence for what happened" block -> per-decision "Evidence (n)" disclosures plus a time-rail disclosure.
- **Debrief**: "Recovery gap and proposed fixes" -> "Recovery gap", "Recommended corrections" with a four-state tracker, "Uncertainties", "Next actions". "Proposed. Creating Jira work items ... arrives in M8" text removed; the remediation preview is live.
- **History**: integrity labels "Failed integrity check" / "Cannot be checked" -> "Tampered" / "Unverifiable" (`components/history/records.ts`). Same statuses, same behaviour.
- **Settings and Runbooks**: "planned for M2/M3/M6/M9" lines removed (milestone codes are gone by design, tested in `Shell.test.tsx`, `Settings.test.tsx`).
- **Added, not in the old UI**: Appearance control, collapsible rail and mobile drawer, Ask Rovo entry, Crisis room screens, run comparison, fix review, first-run guide, `?preview=` crisis fixtures.

No functional gap was found, so none needed a UI fix.

## Defects found and fixed here

1. Dev-preview only: the Crisis room did not load on the Vite preview. The real resolvers call `node:crypto` `createHmac`, which does not exist in the browser, so the page stayed on "Checking team rooms" with six console errors. Fix: a preview-only HMAC-SHA-256 shim (`static/app/src/dev/nodeCryptoShim.ts`, aliased in `static/app/vite.config.ts` only when `SF_PREVIEW=1` on `serve`), built on a new `sha256Bytes` export in `shared/remediation/sha256.ts` (`sha256Hex` unchanged). Test `test/previewCryptoShim.test.ts` proves it equals node's HMAC for short, block-size and long keys. Not in the Forge bundle (fixture grep of `static/app/build` finds no preview strings). `src/crisis` and `src/remediation` are unchanged.
2. Test gap: no test pinned that participant ids are opaque, stable in a room and different across rooms. Added `test/crisisAlias.test.ts`.
